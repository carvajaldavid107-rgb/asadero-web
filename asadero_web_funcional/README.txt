ASADERO EL POLLO FELIZ — PÁGINA WEB DE DEMOSTRACIÓN

ARCHIVOS
- index.html: contenido y estructura.
- styles.css: diseño adaptable a celulares y computadores.
- app.js: productos, carrito y envío del pedido a WhatsApp.

CÓMO PROBARLA
1. Descarga y descomprime el ZIP.
2. Abre la carpeta.
3. Abre index.html con Chrome, Edge o Firefox.
4. Agrega productos al pedido, cambia cantidades, prueba "Vaciar pedido" y completa el formulario.
5. Para probar el envío real por WhatsApp, configura primero el número real siguiendo el paso siguiente.

CONFIGURACIÓN OBLIGATORIA ANTES DE PUBLICAR
1. Abre app.js en un editor de código.
2. Busca al principio el objeto BUSINESS.
3. Cambia whatsapp por el número real del negocio en formato internacional, solo números. Colombia: 57 + número móvil. Ejemplo de formato: 573001234567. No uses el número de ejemplo como si fuera real.
4. Cambia address por la dirección real.
5. Revisa los productos y precios del arreglo products en app.js.
6. Actualiza horarios, nombre, textos y datos de contacto en index.html.
7. Prueba en un celular y computador antes de compartir el enlace.

QUÉ FUNCIONA
- Catálogo generado desde app.js.
- Carrito: agregar, subir/bajar cantidades y eliminar productos.
- Cálculo automático del total.
- Formulario de nombre, tipo de pedido, dirección y notas.
- Validación de carrito vacío y dirección requerida para domicilio.
- Generación de un mensaje de pedido y apertura de WhatsApp.
- Menú móvil adaptable.

QUÉ NO INCLUYE
- No guarda pedidos en una base de datos ni envía pedidos automáticamente.
- No cobra en línea.
- No confirma inventario, domicilios ni disponibilidad; el negocio debe confirmarlos por WhatsApp.
- No tiene panel de administración.
- Las imágenes externas necesitan internet y pueden cambiar o dejar de estar disponibles.
- No incluye dominio ni alojamiento.

NOTAS IMPORTANTES
Los productos, precios, dirección y nombre son datos de demostración. No publiques la página para un negocio real sin su autorización y sin revisar la información.
Para publicar en internet puedes usar un alojamiento estático como GitHub Pages, Netlify o Cloudflare Pages. El dominio propio es opcional y puede tener costo.
